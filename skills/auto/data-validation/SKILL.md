---
name: data-validation
description: Use when you need to validate data inputs and outputs to ensure correctness and compliance with specifications.
---
- Confirm that all input data is in the expected format before processing.
- Check for and handle missing or invalid data appropriately.
- Ensure that all calculations are performed using the correct data types.
- Validate that output data adheres to the required structure and format.
- Implement checks for duplicate entries and handle them according to the specifications.
- Review that all monetary values are represented in the correct format (e.g., cents).
