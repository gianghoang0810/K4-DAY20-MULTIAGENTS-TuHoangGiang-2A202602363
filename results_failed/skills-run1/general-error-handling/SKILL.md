name: general-error-handling
description: Use when you need to ensure that error handling and logging conventions are followed in your code.
---
- Verify that all error messages are captured and logged according to the specified format.
- Ensure that only relevant error levels (ERROR, CRITICAL) are included in the output.
- Confirm that timestamps are converted to UTC and formatted correctly.
- Check that the structure of the output file matches the required schema.
- Include repeat counts for error messages as specified.
- Validate that all necessary fields are present in the output.
