---
name: testing-and-documentation
description: Use when you need to ensure that your code is well-tested and documented according to project standards.
---
- Write unit tests for all public functions to verify their behavior.
- Document all functions with clear docstrings that describe parameters and return values.
- Maintain a CHANGELOG.md to record all changes and fixes made to the codebase.
- Ensure that all tests are run and pass successfully before finalizing changes.
- Include regression tests for any bugs that have been fixed.
- Follow naming conventions for test files and functions to ensure they are discoverable by the testing framework.
